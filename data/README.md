# PostTrainBench⁰ derived data

This directory contains compact, de-identified tables used by the checked
figures. It does not contain task examples, model checkpoints, raw API traces,
credentials, infrastructure identifiers, or internal filesystem paths.

`blog_run_summary.csv` contains the grouped 51-run snapshot used in the
PostTrainBench⁰ research blog: 34 Qwen2.5-3B-Instruct runs and 17
Qwen3-4B-Base runs. It reports counts, means, and observed ranges rather than
raw traces or checkpoints.
